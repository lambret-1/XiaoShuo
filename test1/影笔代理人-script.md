# 影笔代理人 · 剧本（第 1–10 集）

## 第 1 集

> 预估 46.4 秒 / 目标 120 秒 · 开场钩子：画室主人站在画架前，脚下干干净净，没有影子（第 0 场第 0 拍兑现） · 结尾悬念：契约完成的瞬间，沈砚的墨痕发烫——不是常规刺痛，是一种共鸣
> 认领爽点：悬念钩

### 第 1 场 · S01（黄昏）

人物：C01、C02　道具：P01

黄昏画室，沈砚站在画架前执笔，镜头缓缓下移——他脚下的地板干干净净，没有影子。

门被推开，周明缩着肩膀走进来，目光落在沈砚背上。

**C02**（声音很小，犹豫）：这里是……能画画的地方？

**C01**（声音很平，笔尖没停）：白天画人像。黄昏以后，画别的。

周明咽了口唾沫，目光往下移——看到沈砚脚下没有影子，后退半步。

**C01**（转身面对他，眼睛不动）：坐。说吧，你想让影子替你做什么。

**C02**（越来越低，拳头攥紧）：我想让它替我去开会。跟主管说我要离职，把三年的事全说出来。

**C01**（右手拇指擦了一下手背上的墨痕）：规则你清楚吗？影子替你做一件事，你付一项人格代价。不可逆。

沈砚落笔，照心纹从纸面中央扩散，墨线游走，纸面嘶嘶作响。

纸上画面清晰：缩在教室角落的男孩→站在主管面前攥拳的周明→会议室讲台上张嘴发不出声的周明。

墨字浮现：你要的不是离职。你要的，是愤怒的勇气。周明的脸白了，眼眶红了。

**C01**（笔尖落下第二道第三道纹路）：代价是——永久剥离你的愤怒。

**C02**（闭眼，声音沙哑，泪掉下来）：我愿意。

三道纹路交汇，纸边碳化卷起，飘下影屑。周明的影子动了动，重新贴回地板。

周明推门离开。画室里，沈砚低头看右手——墨痕在发烫。不是常规刺痛，是一种若有若无的共鸣。

## 第 2 集

> 预估 46.3 秒 / 目标 120 秒 · 开场钩子：周明迟到五分钟，但步伐稳得不像他平时的样子——影子替他来开会了（第 0 场第 0 拍兑现） · 结尾悬念：沈砚第一次远程感知——墨痕比昨天又深了一分
> 认领爽点：打脸

### 第 1 场 · S02（日光灯上午）

人物：C02　道具：P01

长条形会议室坐了十二个人，主管赵国栋坐在主位，手指不耐烦地敲桌面。

门开了，周明走进来。头发比平时整齐，手里攥着文件夹，步伐很稳。

**C02**（声音不高，但会议室里每个人都听得清）：赵主管。这是近三年，我参与的十一个项目的原始图纸。

周明又拿出一叠纸放在桌上。主管的脸色变了。

**C02**（目光平静得可怕）：这是项目组的内部邮件记录。一共一百四十七封。

**C02**（一字一句）：我知道。上个月城西综合体，你把我的设计拿去评了省优。

周明从文件夹里拿出最后一张纸，放在桌上。

**C02**（顿了顿，看着主管的眼睛）：这是我的离职申请。今天生效。

**C02**（一字一句，平静）：还有，我不是废物。

周明转身走出会议室。门在他身后关上。十二个人面面相觑。

### 第 2 场 · S01（上午阳光）

人物：C01

同一时刻，一心堂画室。沈砚坐在画架前，闭着眼睛。

他的右手手背上，墨痕在发烫。不是刺痛，是温热的、流动的东西。

他「看见」了——一间会议室，一个穿灰工装的男人站起来，把一叠纸放在桌上。

他听见那个男人说：我不是废物。然后，连接断了。

沈砚睁开眼睛。低头看右手，墨痕比昨天又深了一分，边缘有纹路蔓延。

## 第 3 集

> 预估 59.2 秒 / 目标 120 秒 · 开场钩子：苏听晚的目光落在沈砚脚下——没有影子（第 0 场第 0 拍兑现） · 结尾悬念：苏听晚的影子边缘平整，像一张剪下来贴在地板上的黑纸片
> 认领爽点：世界观扩展

### 第 1 场 · S01（上午阳光）

人物：C01、C03　道具：P02、P03

门被敲响，很轻，很有礼貌，三下。

**C03**（温和，清晰）：请问，这里是一心堂画室吗？

沈砚打开门。门外站着一个女人，二十六七岁，穿米白色风衣，手里抱牛皮纸档案袋。

苏听晚走进画室，目光快速扫了一圈——画架、速写本、木格窗。然后她的目光停住了，停在沈砚脚下。干干净净。没有影子。

**C03**（语气自然）：我叫苏听晚，市档案馆的。我在整理旧档案，发现了关于一心堂的记录。

苏听晚从档案袋里拿出几张复印件，放在桌上。

**C03**（目光直视沈砚）：近五年来，我市登记在案的不明原因衰竭死亡，一共七起。都住在梧水街周边。

**C01**（平静）：你想知道什么？

**C03**（声音很轻，但很认真）：什么是影子的契约。还有——为什么你没有影子。

沈砚沉默了。他的目光往下移，落在苏听晚的脚下。

苏听晚的影子，贴在木地板上。但不一样。它太平静了。边缘平整，轮廓稳定，像一张剪下来贴在地板上的黑纸片。

沈砚盯着那团影子，看了很久。他见过无数人的影子，但从来没有见过这样的影子。安静。干净。像一间没有人住过的房子。

**C03**（注意到他的目光）：怎么了？我的影子……有什么不对吗？

**C01**（收回目光）：没有。

苏听晚临走前，从风衣口袋里拿出一枚银色的书签，放在桌上。

**C03**（把书签推到沈砚面前）：这是我在旧物里找到的，夹在一本1920年的速写本里。上面有很奇怪的纹路。

沈砚的目光停在那枚书签上。书签背面刻着两个小字：归一。右手手背上的墨痕，突然烫了一下。

## 第 4 集

> 预估 56.3 秒 / 目标 120 秒 · 开场钩子：沈砚在苏听晚手腕画一道墨线——她低头，第一次看见了影子（第 0 场第 0 拍兑现） · 结尾悬念：满街的影子都在说话，只有苏听晚的影子纯白安静——像一片异类
> 认领爽点：恐怖爆点

### 第 1 场 · S01（黄昏）

人物：C01、C03　道具：P01

黄昏画室，沈砚拿起一支笔，蘸着松烟墨，抬起苏听晚的左手。

他在她手腕内侧，轻轻画了一道很细的墨线，像一根头发丝。

**C01**（平静）：临时照心纹。不会缔约，只是让你在一小时内看见影子。

苏听晚低头，看见了自己脚下的影子——她能「感觉」到它了。

### 第 2 场 · S03（黄昏路灯）

人物：C01、C03

两人走在老街石板路上，路灯把影子拉得很长。

苏听晚看见一个卖水果的小贩，脸上挂着职业微笑。但他的影子在地面上一遍遍重复：少找了五块钱……

**C03**（声音发紧，后背起鸡皮疙瘩）：他的影子在说话？

**C01**（声音很平）：影子说的，是主人不敢说出口的话。

苏听晚继续走，看见更多——穿西装的男人影子扭曲着骂傻X，女孩的影子在哭他不爱我，老人的影子缩成一团说别死。

### 第 3 场 · S04（夜晚暗影）

人物：C01、C03

暗巷里，一个男人靠墙喝酒，眼神空洞。他的影子不在地面上——半悬浮在他身后，像被风掀起的黑纸片。

影子的嘴一张一合，发出尖锐嘶鸣。一只黑色的手按在男人头顶，他的身体轻轻颤了一下。

**C01**（平静）：在抽他的人格。第二阶段空洞化。

苏听晚想走过去，沈砚拉住了她的胳膊。

**C01**（看着她）：我是代理人。我只见证，不救赎。

### 第 4 场 · S03（黄昏路灯）

人物：C01、C03

回到老街灯光下，苏听晚深深吸了一口气。

她低头看自己的影子——满街的影子都在说话都在晃，只有她的影子纯白安静，没有任何声音。

**C03**（犹豫）：我的影子……是不是有什么不对？

沈砚的脚步顿了一下，没有回头。

**C01**（回避）：你的影子安静，也许只是因为你没有什么不敢说的话。

## 第 5 集

> 预估 29.2 秒 / 目标 120 秒 · 开场钩子：周明老婆跟他吵架，他一点都不生气（第 0 场第 0 拍兑现） · 结尾悬念：残卷里记录了上一个无影画师——他后来怎么样了？
> 认领爽点：悬疑推进

### 第 1 场 · S01（下午）

人物：C01、C02

周三下午，周明坐在画架对面的木椅上。和三天前相比，他的精神好了一些，背也挺直了，但眼神里有一种说不出的空。

**C02**（困惑）：我老婆跟我吵架，我一点都不生气。我是不是……哪里不对了？

**C01**（平静）：代价开始显现了。愤怒已经永久剥离。你会记得那些委屈，但再也感受不到怒火。

周明沉默了很久。他低下头，看着自己的手。

### 第 2 场 · S05（昏暗库房）

人物：C03　道具：P03

市档案馆地下库房，苏听晚抱着牛皮纸档案袋走下石阶。

库房管理员打开最里侧的铁门。苏听晚走进去，从书架最底层抽出一本泛黄的旧册子。

册子的封面上写着：梧水街影契录。她翻开第一页，上面画着一个没有影子的人。

苏听晚的手指停在那页上。她翻到最后——最后一页的字迹模糊，只看到一行：无影画师，代价是……后面被撕掉了。

## 第 6 集

> 预估 20 秒 / 目标 120 秒 · 开场钩子：茶香巷的风停了，空气里浮着洗不掉的墨腥气（第 0 场第 0 拍兑现） · 结尾悬念：一黑一白一热一冷，僵持了不到三秒——纯白的慢慢淡了
> 认领爽点：道具觉醒

### 第 1 场 · S04（夜晚暗影）

人物：C01、C03、C04　道具：P02

夜深了，茶香巷的石板路被薄薄的水汽浸湿。沈砚和苏听晚守在归一盏茶馆对面的暗影里。

巷子里的风停了。本该飘出来的油锅味、潮气味，齐齐被压下去。空气里浮着一层极淡的、洗不掉的墨腥气。

茶馆的门开了。一个黑影走出来，脸完全被黑暗遮住。

沈砚的右手墨痕突然发烫。他从口袋里拿出那枚银书签，放在地上。

书签里渗出一缕极淡的纯白气息，和墨痕里那股温热的墨色共鸣，在空气里无声地对峙。

纯白的很弱，像落在水面的雪花。墨色的很沉，像井底的水。一黑一白，一热一冷，僵持了不到三秒。

然后，纯白的慢慢淡了，消散在空气里。墨色的共鸣也随之退去，缩回了沈砚的右手墨痕里。

黑影退进了茶馆，门关上了。巷子恢复了安静。

## 第 7 集

> 预估 12.5 秒 / 目标 120 秒 · 开场钩子：阴冷的风从铁门缝隙溢出，裹挟着尘封百年的气息（第 0 场第 0 拍兑现） · 结尾悬念：悬浮半空的纯白虚影剧烈震颤，像漂泊半生的归鸟终于寻到归途
> 认领爽点：悬疑推进

### 第 1 场 · S04（夜晚暗影）

人物：C01、C03　道具：P02

阴冷的风从铁门缝隙里缓缓溢出，裹挟着尘封百年的古老气息。

空灵的呼唤穿透铁皮，温柔又执着。

悬浮半空的纯白虚影剧烈震颤，细碎微光不断冲撞铁门，像漂泊半生的归鸟终于寻到归途。

苏听晚脚下那团纯白影子悬在沈砚袖边，微光一明一灭，像呼吸没接上。

黑白两道纹路悬在半空，像被一只无形的手按住，谁也不肯先退。

## 第 8 集

> 预估 16.9 秒 / 目标 120 秒 · 开场钩子：巷子里的风停了，空气里浮着墨腥气（第 0 场第 0 拍兑现） · 结尾悬念：影商退了，但他留下一句话——你的影子，还在吗？
> 认领爽点：规则反制

### 第 1 场 · S04（夜晚暗影）

人物：C01、C03、C04　道具：P02

隔了两晚，影商又来了。那天黄昏沈砚从画室下来倒垃圾，刚走到茶香巷口，就觉出不对。

黑影从暗影里走出来，脸完全被黑暗遮住。空气里的墨腥气比上次更浓。

**C04**（阴冷的回声）：代理人，你坏了我的生意。

沈砚没有说话。他抬起右手，墨痕在发光。左手拿出银书签，纯白气息渗出。

黑白两道纹路同时压向黑影。黑影后退了一步，空气里的墨腥气开始颤抖。

**C04**（阴冷的回声，然后黑影退去）：你以为你能一直挡着？你的影子，还在吗？

## 第 9 集

> 预估 30.4 秒 / 目标 120 秒 · 开场钩子：陈婆婆家的门半掩着，只点着老式煤油灯（第 0 场第 0 拍兑现） · 结尾悬念：沈砚按在自己胸口——心跳还在，但有什么东西，在很远的地方正在醒来
> 认领爽点：身世揭秘

### 第 1 场 · S03（黄昏）

人物：C01、C05

傍晚，沈砚下楼还拖把。陈婆婆家的门半掩着，屋里没开灯，只点着那盏老式煤油灯。

陈婆婆坐在桌边，手里捏一块旧绒布，一下一下擦着灯罩。

**C05**（慢悠悠的）：小沈啊，你坐。我跟你说个事，憋了很多年了。

**C05**（看着灯罩）：你这家画室，以前不是这个名字。最早的主人，也是一个没有影子的人。

**C05**（声音很轻）：他跟你一样，黄昏以后替人画影子。但有一天，他消失了。有人说他去找自己的影子了。

沈砚沉默了。他想起苏听晚临走前问的那句话：你的影子，它还在吗？

他伸出右手，按在了自己的胸口。心跳还在。但他知道，有什么东西，不在了。或者说——有什么东西，在很远的地方，正在醒来。

## 第 10 集

> 预估 17.5 秒 / 目标 120 秒 · 开场钩子：城郊旧墓园荒废十年，黄昏夕阳把残碑影子拉得老长（第 0 场第 0 拍兑现） · 结尾悬念：有什么东西，在很远的地方，正在醒来——不是周明的影子，是他自己的
> 认领爽点：大爆点

### 第 1 场 · S06（黄昏夕阳）

人物：C01、C03　道具：P01、P02

城郊的旧墓园，荒废快十年了。坟头一座压着一座，石碑东倒西歪，缝里长出半人高的荒草。

黄昏时分，夕阳从西边斜过来，把一园残碑的影子拉得老长，交叠在荒草里。

苏听晚拿着一份新的讣闻，递给沈砚。第七个了。

沈砚站在墓园中央，右手墨痕又烫了一下。他抬起头，看着远方的夕阳。

风停了。墓园里一片安静。沈砚感觉到，右手墨痕里那股温热的共鸣，和远处某个地方，有什么东西在回应。

不是周明的影子。不是任何一个缔约人的影子。是他自己的。

沈砚站在黄昏的墓园里，脚下干干净净，没有影子。但他知道，在很远很远的地方，有一团影子，正在醒来。
