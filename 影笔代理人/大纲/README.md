## 1. 核心世界观设定（三层世界架构）

### 【浅层世界：人间俗世｜第1–320章主要舞台】

地点：南方老城梧水街为起点，逐步向外扩散至省内、全国各大城市。

底层基础：**黄昏是影子力量峰值；正午强光压制影子，无法缔结影契。**

影子是人类内心执念、情绪、阴暗面的具象投影。普通人影子依附本体，情绪波动时轮廓轻微晃动。

**影契交易**：人可以和自身影子订立契约，影子替人完成不敢执行的心愿；代价是永久剥离一项人格特质，记忆保留，但对应情绪能力永久缺失。

**空洞化**：契约被篡改，影子拒绝回归本体，持续掠夺本体人格，当事人逐步丧失全部情绪，最终脏器不明衰竭死亡。尸检统一标注「不明原因衰竭」，常规医学无法找到病理损伤。

**黑市影商**：人为篡改影契纹路，诱导普通人缔约，批量收割人格碎片供给本源。

### 【中层世界：影子秩序｜第321–640章解锁】

影子存在完整阶级与族群生态，影子依靠**人格碎片**维持存在，存在"饥饿"机制。

影子等级划分：游离影 → 觉醒影 → 脱壳影 → 执事影 → 本源影

- **游离影**：普通人常规影子，无独立意识
- **觉醒影**：产生微弱自我意识，能和本体对话
- **脱壳影**：脱离本体独立游荡，可在灰域长期存活
- **执事影**：九影执事，始祖影分化，承载单一极端人格
- **本源影**：始祖影本体，黑暗聚合体

**影域/灰域**：城市内情绪浓度极高区域（医院、殡仪馆、墓园、旧创伤老宅），影子力量暴涨，容易发生脱壳、空洞化。不同城市拥有独立影域，影域之间存在边界，影子族群会争夺地盘。

**历代代理人遗迹**：散落全国各地旧老屋、地下密室，留存上代代理人速写本、残损影契、破碎影墨，记录千年轮回往事。

### 【深层世界：本源规则空间｜第641–1000章解锁】

**千年无影代理人轮回机制**：世界底层原生规则，会周期性挑选代理人。代理人在承受巨大精神创伤时，极易触发影笔本源力量，剥离自身影子人格，被剥离的黑暗会归集到本源，代代叠加。

**始祖影真相**：并非十年前少年沈砚单独创造，是千年所有无影代理人剥离出去的黑暗总和。少年沈砚只是轮回终末的承载容器，十年前的剥离动作，完成了全部黑暗的归集。

**世界底层规则**：规则本身倾向于"分割自我"，引导人类与代理人切割痛苦，以此维持影子循环。本篇章核心冲突：打破这套千年既定规则。

> **核心底层真相（800章之后揭露）**
> 每一代无影代理人剥离影子之后，分离出的纯白善意碎片，都会汇聚沉淀，等到终末轮回，凝聚成型，也就是苏听晚。苏听晚不是单一一次剥离的产物，是千年历代代理人全部善意聚合体。

## 2. 影契与影子完整规则体系

### 影笔

- **材质**：松烟墨混合本源之力，落笔生成影契纹路。
- **代理人定位**：**见证者，不可以强行替委托人缔约，不能主动修改契约**，只能用照心纹揭露委托人潜意识真实愿望。委托人看到本心之后，拥有终止契约的权利。
- **印记**：每次缔结契约，代理人右手生成墨痕。墨痕深度、蔓延范围，和唤醒的人格碎片量级成正比。墨痕是代理人与万影本源的连接印记。

### 影契三道固定纹路（缺一不可）

1. **照心纹**：映照表层愿望与潜意识真实愿望，无法造假。是契约第一道防线。
2. **代行纹**：影子承诺完成指定事件，约定行动边界。
3. **偿价纹**：契约生效后，缓慢剥离指定人格特质，不可逆。代价存在滞后性，一般3–7天逐步生效，附带连锁现实后果。

### 代价硬性规则（红线，不可改动）

1. 剥离的是**人格特质/情绪能力**，**不会删除记忆**。记忆保留，但是对应的情绪感受消失。
   - 例：剥离思念，记得故人样貌故事，但再也无法产生怀念；剥离愤怒，记得委屈遭遇，但不会燃起怒火。
2. 代价生效存在滞后，不会瞬间生效。
3. 代价会带来连锁现实负面影响，不是单纯"少一种情绪"。
4. 代理人不能随意指定代价，代价由照心纹读取本心自动生成。

### 影子基础特性

1. 影子的声音，永远是本体干涩的回声，不会诞生全新独立人声。
2. 影子无法脱离"主人本心"凭空创造愿望，影子所有诉求根源来自人类内心。
3. 影子在强光下力量大幅衰减，正午无法缔结契约。
4. 影子吞噬人格碎片后会变强，过度吞噬会扭曲。

### 空洞化完整阶段

- **阶段1**：影子躁动，夜晚脱离本体短时间外出，当事人情绪开始麻木。
- **阶段2**：影子拒绝回归本体，持续抽取人格，当事人情感大面积消失。
- **阶段3**：完全空洞，无喜怒哀乐，脏器缓慢衰竭，最终死亡。
- **阶段4**：死者影子化为游离脱壳影，流入灰域，被黑市或本源吸收。

### 黑市篡改契约规则

黑市影商改动偿价纹，放大代价，诱导委托人许下虚假愿望，强行加速影子脱壳，收割人格碎片。黑市契约属于**伪影契**，稳定性极差，空洞化概率极高。

## 3. 人物档案

### 沈砚｜主角｜影笔代理人

- **年龄**：开篇27岁
- **外貌**：身形清瘦，眉眼安静，肤色偏白；右手手背带有洗不掉的墨痕，随剧情不断向手腕、小臂蔓延；脚下永远没有影子。常穿深色简约上衣。
- **随身物品**：速写本、影笔、旧怀表（时间停留在十年前剥离影子的时刻）。
- **背景**：17岁遭遇巨大创伤，触发影笔本源，剥离全部影子人格，失去绝大部分情绪，成为无影代理人，在梧水街经营一心堂画室。白天绘制人像旧照，黄昏接待影契委托人。
- **十段成长弧光**：见第10节。
- **核心矛盾**：少年时期想要一刀切除痛苦获得安宁，却成为千年轮回终末容器，历代黑暗归集于此，黑暗流落人间造成无数空洞化悲剧。

### 苏听晚｜核心女主｜档案馆研究员

- **年龄**：开篇26岁
- **外貌**：气质柔和，常年携带卷宗与一枚银书签；脚下影子平整静止，永远不会随情绪晃动。
- **背景**：千年历代无影代理人剥离出来的纯白善意聚合体，在十年前沈砚剥离影子那一刻，凝聚独立人形。长期拥有残缺梦境，梦境是历代代理人的破碎记忆，尤以少年沈砚的记忆最多。银书签是上代代理人遗物，可短暂压制躁动影子。
- **人物功能**：档案考据、线索推理，平衡沈砚冰冷视角，后期揭露千年本源身世。

### 陈婆婆｜房东，上代代理人见证者

- **年龄**：70+
- **外貌**：苍老温和，常年擦拭煤油灯，保管上代代理人遗留木匣、焦黑残损影契。
- **背景**：亲眼见证上一任无影代理人的结局，知晓轮回预言，静静等待轮回终局节点。
- **功能**：伏笔投放，提供古老传说、实物残片，在关键节点放出关键信息，不会一次性全盘托出。

### 林叙｜法医

- **年龄**：开篇30岁
- **外貌**：理性克制，常备一次性橡胶手套，随身带解剖笔。
- **背景**：妹妹林晚死于空洞化，常规尸检无任何病理异常。顺着档案馆卷宗线索找到一心堂，代表现实世界理性视角，负责提供空洞化案件物证。
- **功能**：提供现实层面证据，平衡超自然奇幻设定，从普通人视角见证影子世界。

### 始祖影｜本源聚合体（非传统反派）

- **形态**：流动巨大黑影，无固定轮廓，声音是沈砚的回声。
- **来源**：千年所有无影代理人剥离的黑暗、悔恨、恐惧、执念全部归集而成。十年前沈砚的剥离，完成归集。
- **诉求**：不是毁灭人类，是等待本体接纳这一整份被世代抛弃的黑暗。千年独自承载无尽负面情绪，长久孤独。

### 九影执事｜始祖影分化九种核心人格碎片

> 九影不会杀害沈砚，只会制造幻境，引导沈砚看见、理解、接纳每一部分自我，等待人格归位。

1. **贪**：向外抓取，贪婪，欲望，黑市早期幕后主导
2. **嗔**：轮廓尖锐震颤，怒火，不甘，怨恨
3. **痴**：沉溺幻境，执念，怀念，困于过往
4. **怯**：不断退缩，恐惧，逃避，不敢面对真相
5. **妒**：紧盯他人影子，羡慕，渴求完整
6. **憾**：持续飘落影屑，长久悔恨，无法释怀的遗憾
7. **妄**：影子膨胀，制造虚妄假象，自我欺骗
8. **执**：轮廓僵硬，顽固偏执，死守既定宿命
9. **漠**：平坦无起伏，极致麻木，冷漠旁观

### 历代无影代理人（轮回线配角，中层/深层篇章登场）

每一代代理人都经历相似轨迹：遭遇创伤→剥离影子→黑暗汇入本源，善意碎片飘散沉淀，最终走向崩解。在遗迹、幻境、残契中登场，展示千年轮回的悲剧循环。

### 黑市影商（阶段性对手）

普通人被欲望驱动，学习篡改影契纹路，以收割人格碎片牟利，属于欲望的执行者，并非本源层面敌人。

### 单元案件委托人（轮换登场，每案独立人设）

普通人，被执念驱动，前来缔结影契。每个委托人都是一面镜子，映照沈砚自身的创伤与选择。

## 4. 场景总设定

### 浅层人间场景

#### 一心堂画室（核心主场，梧水街二楼老铺）

- **视觉**：老式木格窗，光束浮动尘埃；泛黄开裂墙纸，挂满炭笔速写；老旧木地板；沈砚站立位置地面永远干净，无影子。
  - 影契燃烧：外焰暖黄，内焰缠绕细墨黑纹路；不产生浓烟，飘散半透明细碎影屑，普通人看不见，沈砚可看见。影屑如同黑色细绒毛，无实体。
- **气味**：常态：松烟墨、旧纸张、老木潮湿霉味。缔约时增加冷腥影屑气息，仅沈砚能感知。
- **声音**：老街车流、木地板咯吱声、笔尖摩擦速写本沙沙声。缔约时外界杂音压低，墨流淌纸面有细微嘶嘶声，影子回声干涩空旷，画纸碳化噼啪轻响。
- **触感**：缔约室温下降，委托人手臂起鸡皮疙瘩；沈砚落笔时手背墨痕发烫刺痛，痛感沿手腕短暂蔓延。
- **规则**：正午强光直射无法缔约，委托只接黄昏与夜晚。

#### 梧水街老城

新旧建筑交织，老街店铺林立，黄昏光影层次丰富。城市灰域分布：老医院、旧殡仪馆、废弃墓园。

#### 黑市影巷

老城深处隐秘巷道，黑市商人聚集，私自篡改影契，批量诱导缔约，空气中浓郁同源墨息。

### 中层影域场景（321章后解锁）

各地城市灰域扩张形成稳定影域，影子族群盘踞。不同影域风貌不同：

- **医院影域**：无尽白色长廊，遍地散落影屑
- **墓园影域**：无数半透明影子徘徊，安静沉默
- **前代代理人遗迹密室**：布满古老影契纹路，残卷、枯墨，残留旧时代影子执念

### 深层本源空间（641章后解锁）

影之本源，无尽流动墨色虚空，无数历代代理人破碎记忆碎片漂浮于此。始祖影的栖身之地。

## 5. 人物习惯、小动作、微表情素材库

### 沈砚

1. 思考：右手拇指反复摩挲手背墨痕；墨痕疼痛发作，指尖攥紧，指甲轻掐掌心，面部保持隐忍平静。
2. 合上速写本，指节轻叩本子边缘三下，固定仪式动作。
3. 情绪空白阶段，眨眼频率低，目光平静；情绪复苏阶段，眨眼增多，瞳孔轻微收缩。
4. 画具固定摆放；接待委托人微微侧身，不会长时间直视对方双眼。
5. 回忆闪回：取出旧怀表捏在手心，不打开，感受冰凉表壳。

### 苏听晚

1. 翻阅卷宗，银书签压住书页右上角；思索时指尖捻动书签链条缓慢转圈。
2. 感知暗影躁动：指尖发凉，收紧书签，呼吸轻微放缓。
3. 倾听时微微侧头；整理案卷会抚平纸页褶皱，轻微整理癖。
4. 犹豫时轻咬下唇，说话结束短暂停顿。

> 特殊设定：影子永远平整贴地，不会随情绪晃动。

### 陈婆婆

1. 黄昏擦拭煤油灯玻璃，擦拭完毕望向窗外黄昏。
2. 谈及影契、上代代理人，手护住膝上木匣。
3. 语速缓慢，安静倾听，偶尔轻轻点头。

### 林叙

1. 习惯双臂交叉抱胸；讨论死亡案件，摩挲口袋解剖笔。
2. 内心受到冲击，反复摘下、重新戴上橡胶手套。

### 始祖影

无实体肢体，黑影形态表达情绪：愤怒时黑影翻涌扩张；悲伤时轮廓收缩飘散影屑；平静时固定如黑幕。声音为沈砚回声。

### 九影执事黑影动作

- **贪**：影子蠕动向外抓取
- **嗔**：轮廓边缘尖锐震颤
- **痴**：反复幻化过往画面
- **怯**：不断向后退缩
- **妒**：紧盯他人影子
- **憾**：边缘持续飘落影屑
- **妄**：影子膨胀制造假象
- **执**：轮廓僵硬固定
- **漠**：影子平坦无起伏

## 6. 案件分级体系

> 每级案件有固定冲突模式，轮换使用，1000章不会重复。

### E级日常案｜1–160章｜普通人微小执念

冲突：普通人生活困境，诉求简单，影子完成任务后正常回归。代价剥离普通情绪。
功能：铺垫世界观，展现人间百态，细微伏笔埋设。
示例：开篇周明案，自卑女孩演讲案，老人怀念老伴案。

### 少年回忆片段（第四篇章幻境素材）

雨砸在老旧窗棂上，哗哗的声响裹住整间老屋。

少年沈砚跪在地板，面前摊开速写本，松烟墨在瓷碟里静静泛着冷光。他不过十七岁，眼底被无尽的思念与愧疚填满，身后影子紧紧贴住地面，轮廓蜷缩，如同在无声哭泣。

上代代理人站在阴影里，声音平静，不带规劝："影笔可以剥离你的影子，带走所有痛苦、悔恨、执念与悲伤。代价是，你将失去这一部分自我，再也感受不到。一旦落笔，无法反悔。"

少年指尖攥紧画笔，指节发白。

"只要没有这些情绪，我就不会再痛了，对吗？"

"你不会痛，但你也不再完整。影子承载你的阴暗，剥离它，等于切掉你的一半。"

少年没有听进去。巨大的悲伤日夜啃噬他，他只想逃离这份煎熬。

"画吧。"

他拿起影笔，落在纸面。照心纹、代行纹、偿价纹依次铺开。

身后的影子缓缓脱离地面，漆黑轮廓与他一模一样，安静立在他面前。影子没有声音，只是静静望着少年。

"我不要痛苦，不要愧疚，不要思念。"少年低声，"把这些全部带走。"

笔尖落下最后一道本源纹路。

墨色翻涌，巨大的拉扯感席卷房间。少年看着自己的影子被契约强行剥离，从他身上撕裂出去。无尽的黑暗被抽离，凝聚成一团厚重黑影。一缕极淡的纯白微光，从黑影边缘分离，飘向远方。

剧痛过后。

少年低头看向脚下。

地板干干净净，一无所有。

他再也没有影子。

心底翻涌的悲伤、悔恨、执念一瞬间清空，内心变得一片空旷平静。

上代代理人望着那团新生的黑暗，低声预言：

"它会带着千年沉淀的黑暗游荡世间，收集人格碎片，等待你回头接纳它。万影同源，终有一日，深渊会寻上门。"

少年沈砚站在原地，内心一片空白，听不进任何警告。

他以为自己得到解脱。却不知道，被剥离的黑暗，将在人间漂泊整整十年，缠绕千年轮回的宿命。

### 幻境试读片段（第四篇章·痴）

黄昏褪去，一心堂画室的光影骤然扭曲。

周遭的墙壁融化，旧木格窗消失，取而代之的是十年前的老屋。暖黄台灯，桌上摆着故人的茶杯，空气里是熟悉的饭菜香气。

九影执事【痴】的影子在边缘缓缓浮动，没有出声，只是铺展幻境。

沈砚站在房间中央，呼吸微滞。

不远处，那个人坐在桌边，正低头翻看书本，侧颜清晰，是早已离去的亲人。

声音传来，温和熟悉："回来啦？等你很久了。"

沈砚下意识往前踏出一步。心底久违的怀念翻涌上来，这是他剥离影子之后，再也体会不到的情绪。

幻境完美复刻所有细节，温度、声音、气息全部真实。只要留在这里，他可以永远拥有这份幻影，再也不用承受离别之痛。

心底一个诱惑的声音响起：留在这里，不必出去面对那些罪孽，不必面对始祖影，不必看见人间无数空洞化的人。你可以永远留住这一瞬。

沈砚右手手背的墨痕微微发烫。

速写本在他怀中，他想起无数委托人的结局：那个失去思念能力的失独母亲，在幻影消散之后，内心只剩下一片麻木。

所有人都想用影子留住逝去的人，代价是割舍怀念本身。

他停下脚步，没有再靠近。

"这不是真的。"沈砚轻声开口，"我想要的不是幻影，是当年好好告别。"

幻境开始震荡，房间边缘飘出细碎影屑。

【痴】的黑影轮廓微微震颤。

"你明明渴望。"回声响起，"你可以永远留在这里，不用承受失去。"

"逃避怀念，不是解脱。"沈砚缓缓合上眼，"我要接纳这份思念，而不是囚禁幻影。"

幻境碎裂。老屋、灯光、故人全部化作黑色碎屑消散。

沈砚重新回到一心堂画室，黄昏的光线落在木地板上。

他抬手，摸了摸右手蔓延到手腕的墨痕。心底多了一分属于"怀念"的情绪碎片。

【痴】的黑影没有攻击，只是静静缩在墙角，等待归位。

## 12. 写作避坑准则 & 统一设定红线

### 红线（绝对不能违反）

1. ❌ 禁止大规模武力打斗，冲突形式为幻境博弈、契约规则博弈、内心自我审判。
2. ❌ 始祖影、九影执事不是纯粹邪恶反派，是人格碎片，诉求是被接纳，不是毁灭世界。
3. ❌ 剥离代价只去除情绪/人格特质，**严禁删除记忆**，一旦改动会造成设定崩坏。
4. ❌ 万影同源、千年轮回的终极真相，必须在第二篇章末尾才开始铺垫，第六篇章完整揭露，不能提前泄露。
5. ❌ 影子的声音永远是本体的回声，不设计全新独立人声。

### 写作正向准则

1. ✅ 单元案件核心作用：映照沈砚的创伤，作为镜子推动主角内心转变，不是独立小故事。
2. ✅ 基调保持克制，减少直白激烈狗血煽情，依靠细节、留白烘托悲凉感。
3. ✅ 世界观循序渐进解锁，不要一次性抛出全部设定，随剧情逐步揭开。
4. ✅ 伏笔分层埋设，浅层伏笔优先回收，深层伏笔保留到中后期，做到层层递进。
5. ✅ 人物成长缓慢，沈砚情绪复苏是细微渐进式，不会一夜之间性格大变。
