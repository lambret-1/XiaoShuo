## 三、修稿原则（novelist-zh + humanizer-zh）

1. **只改表达，不改事实**：情节、设定、人名、数字、伏笔位置一律保留；不新增原文没有的场景与因果
2. 对话标签「他/她/它 + 说/道」每章 **≤3**，超出改为动作、神态、沉默或直接引语
3. 情绪落到具体身体反应，删形容词式告知与旁白解释
4. 章末停在画面或动作上，不升华、不点题、不给金句
5. 场景细节须「只在此处成立」，清除万能句
6. 抽象情绪词一律换成 `连续性/人物.yaml` 记录的**该人物专属动作**

### 项目红线（README 第12节，绝对不可违反）

1. 禁大规模武力打斗；冲突为幻境博弈、契约规则博弈、内心自我审判
2. 始祖影、九影执事非纯恶，是人格碎片，诉求是被接纳
3. **剥离只去除情绪/人格，严禁删除记忆**
4. 万影同源与千年轮回真相：第二篇末才铺垫、第六篇揭露，**第1卷严禁提前泄露**
5. 影子声音永远是本体的干涩回声
6. 黄昏缔约，正午无契

### 人物专属动作（用于替换抽象情绪词）

- **沈砚**：思考时右手拇指摩挲手背墨痕；合上速写本用指节轻叩封面三下；情绪空白期眨眼频率低；接待时微微侧身、不长时直视对方双眼；回忆时取出旧怀表捏在手心**不打开**；画具固定摆放
- **苏听晚**：银书签压书页右上角；思索时捻动书签链条转圈；**感知暗影躁动时指尖发凉**、收紧书签、呼吸放缓；倾听时微微侧头；整理癖（抚平纸页褶皱）；犹豫时轻咬下唇；影子永远平整贴地不随情绪晃动
- **陈婆婆**：黄昏擦拭煤油灯玻璃；谈及影契时手护膝上木匣；语速缓慢
- **林叙**：双臂交叉抱胸；谈死亡案件时摩挲解剖笔；内心受冲击时反复摘下、重戴橡胶手套

### 影契三纹（顺序与含义不可写错）

照心纹（映表层愿望与潜意识真愿，无法造假）→ 代行纹（影子承诺完成指定事件）→ 偿价纹（缓慢剥离指定人格，不可逆，3–7天滞后）

## 五、快速清理判定口径

| 检查项 | 规则 |
|---|---|
| 对话标签 | 每章 `[他她它]说/道` ≤3。**例外**：角色转述他人话语（如「他说，纯白影子是…」）、档案引文内转述、对话内的「跟她说」，均非叙述标签，不计入 |
| 万能环境句 | 空气仿佛凝固／时间静止／夜色如墨／月光如水／风轻轻吹过／树叶沙沙作响／斑驳的光影 等，命中即改 |
| 抽象堆砌 | 五味杂陈／心潮澎湃／思绪万千／百感交集 → 换具体行为 |
| 套路动作 | 嘴角勾起／眼中闪过一丝／心头一震／瞳孔骤缩／呼吸一滞 → 换第三节人物专属动作 |
| AI连接词 | 然而／因此／此外／与此同时／值得注意的是 → 能删则删 |
| 升华点题 | 章末为哲理宣告，或出现「终于明白／终于懂得／从今往后／注定／或许这就是」→ 删除或改为画面 |
| 旁白告知 | 「他只是一个见证者」式身份宣告、行为后紧跟性格解释 → 改为动作呈现 |
| 句长均匀度 | >0.62 判为节奏偏平（当前160章全部合格） |
