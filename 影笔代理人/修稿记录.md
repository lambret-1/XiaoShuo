## 二、修稿原则（依 novelist-zh + humanizer-zh + 项目自身红线）

### 2.1 原稿主要缺陷（按严重度排序）

1. **标点系统性缺失**（最严重）：逗号大面积丢失，长句连排不断句，节奏被压平。
   例：`黄昏的梧水街光线像被水洗过橘红里掺着灰。`
   → `黄昏的梧水街，光线像被水洗过，橘红里掺着灰。`
2. **对话标签单一**：「他说／沈砚说」密集，缺动作替代。
3. **告知代替呈现**：`他只是一个见证者。` `沈砚的声音没有任何起伏` 这类旁白解释。
4. **章末升华套话**：`像有什么东西正在醒来。` —— 悬念靠宣告而非画面。
5. **画面推进机械**：`画面一转。……画面再转。……` 排比式列举。

### 2.2 修稿动作清单（每章执行）

- 补回标点，重建断句节奏；长短句交错，重要时刻单句成段
- 「他说／她说」全章 ≤3 次，其余换动作、神态、沉默、直接引语
- 情绪一律落到具体身体反应，删除形容词式告知与旁白解释
- 章末停在画面或动作上，不升华、不点题、不给金句
- 场景细节必须「只在此处成立」，清除万能句（夜色如墨、空气仿佛凝固等）
- 保留原文全部情节事实、设定、人名、数字、伏笔位置——**只改表达，不改事实**
- 补足视觉以外的感官：气味、声音、温度、触感（README 第4节场景库已给素材）

### 2.3 项目红线（README 第12节，绝对不可违反）

1. 禁止大规模武力打斗；冲突为幻境博弈、契约规则博弈、内心自我审判
2. 始祖影、九影执事非纯恶反派，是人格碎片，诉求是被接纳
3. **剥离代价只去除情绪/人格特质，严禁删除记忆**
4. 万影同源、千年轮回真相：第2篇末才开始铺垫，第6篇完整揭露，**第1卷严禁提前泄露**
5. 影子的声音永远是本体的干涩回声，不得写成全新独立人声

### 2.4 人物专属动作（README 第5节素材库，须反复复用以立人物）

- **沈砚**：思考时右手拇指摩挲手背墨痕；合上速写本用指节轻叩封面三下；情绪空白期眨眼频率低；接待时微微侧身，不长时直视对方双眼；回忆时取出旧怀表捏在手心**不打开**
- **苏听晚**：翻卷宗用银书签压住书页右上角；思索时指尖捻动书签链条转圈；感知暗影躁动时指尖发凉、收紧书签、呼吸放缓；倾听时微微侧头；有轻微整理癖（抚平纸页褶皱）；犹豫时轻咬下唇。**影子永远平整贴地，不随情绪晃动**
- **陈婆婆**：黄昏擦拭煤油灯玻璃，擦完望向窗外；谈及影契时手护膝上木匣；语速缓慢，偶尔轻轻点头
- **林叙**：双臂交叉抱胸；谈死亡案件时摩挲口袋里的解剖笔；内心受冲击时反复摘下、重戴橡胶手套

### 2.5 影契三纹（不可写错顺序与含义）

1. **照心纹** — 映表层愿望与潜意识真愿，无法造假
2. **代行纹** — 影子承诺完成指定事件，约定行动边界
3. **偿价纹** — 生效后缓慢剥离指定人格，不可逆，3–7天滞后，附带连锁现实后果

## 五、连续性检查规程（每章修完必做）

1. 本章结尾状态（人物位置、时间、天色、墨痕深度、在场人物）与下一章开头是否接得上
2. 人物专属动作是否与 `连续性/人物.yaml` 的 gestures 一致，未擅自新增矛盾设定
3. 影契规则是否触红线（尤其「剥离不删记忆」「影子声音是本体回声」「第1卷不泄露万影同源」）
4. 本章应埋伏笔是否按 `伏笔.yaml` 的 planted 章节落位
5. 委托人姓名、年龄、职业、剥离项与 `时间线.yaml` 的 cases 条目一致
