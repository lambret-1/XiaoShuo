# 影笔代理人 · 剧本（第 1 集）

## 第 1 集

> 预估 48.9 秒 / 目标 60 秒 · 开场钩子：冷开场：画室主人站在画架前，脚下却没有影子——这个空间在黄昏以后做的不是人像。（第 0 场第 0 拍兑现） · 结尾悬念：沈砚低头看右手墨痕发烫，窗外周明的影子指尖蜷缩了一下。契约之外，异常发生了。
> 认领爽点：悬念钩、情感爆点、反转、结尾悬念

### 第 1 场 · S01（黄昏）

人物：沈砚、周明　道具：P01

黄昏画室，沈砚站在画架前执笔，镜头缓缓下移——他脚下的地板干干净净，没有影子。

门被推开，周明缩着肩膀走进来，目光落在沈砚背上。

**周明**（声音很小，犹豫，不敢看脸）：这里是……能画画的地方？

**沈砚**（声音很平，笔尖没停）：白天画人像。黄昏以后，画别的。

周明咽了口唾沫，目光往下移——看到沈砚脚下没有影子，后退半步。

**沈砚**（转身面对他，眼睛不动）：坐。说吧，你想让影子替你做什么。

**周明**（越来越低，拳头攥紧）：我想让它替我去开会。跟主管说我要离职，把三年的事全说出来。

**沈砚**（右手拇指擦了一下手背上的墨痕）：规则你清楚吗？影子替你做一件事，你付一项人格代价。不可逆。

沈砚落笔，照心纹从纸面中央扩散，墨线游走，纸面嘶嘶作响。

纸上画面清晰：缩在教室角落的男孩→站在主管面前攥拳的周明→会议室讲台上张嘴发不出声的周明。

墨字浮现：你要的不是离职。你要的，是愤怒的勇气。周明的脸白了，眼眶红了。

**沈砚**（笔尖落下第二道第三道纹路）：代价是——永久剥离你的愤怒。

**周明**（闭眼，声音沙哑，泪掉下来）：我愿意。

三道纹路交汇，纸边碳化卷起，飘下影屑。周明的影子动了动，重新贴回地板。

周明推门离开。画室里，沈砚低头看右手——墨痕在发烫。

窗外路灯下，周明的影子贴在地面，指尖微微蜷缩了一下。沈砚皱眉。
