# 影笔代理人 · 剧本（第 1 集）

## 第 1 集

> 预估 58.8 秒 / 目标 60 秒 · 开场钩子：沈砚在苏听晚手腕画一道墨线——她低头，第一次看见了自己的影子。（第 0 场第 0 拍兑现） · 结尾悬念：满街的影子都在说话都在动，只有苏听晚的影子纯白安静——像一片异类。
> 认领爽点：悬念钩、视觉奇观、恐怖爆点、结尾悬念

### 第 1 场 · S01（黄昏最后）

人物：沈砚、苏听晚　道具：P01

黄昏画室，沈砚拿起一支笔，蘸着松烟墨，抬起苏听晚的左手。

他在她手腕内侧，轻轻画了一道很细的墨线，像一根头发丝。

**沈砚**（平静）：临时照心纹。不会缔约，只是让你在一小时内看见影子。

苏听晚低头，看见了自己脚下的影子——她能「感觉」到它了。

### 第 2 场 · S02（黄昏路灯）

人物：沈砚、苏听晚

两人走在老街石板路上，路灯把影子拉得很长。

苏听晚看见一个卖水果的小贩，脸上挂着职业微笑。但他的影子在地面上一遍遍重复：少找了五块钱……

**苏听晚**（声音发紧，后背起鸡皮疙瘩）：他的影子在说话？

**沈砚**（声音很平）：影子说的，是主人不敢说出口的话。

苏听晚继续走，看见更多——穿西装的男人影子扭曲着骂傻X，女孩的影子在哭他不爱我，老人的影子缩成一团说别死。

### 第 3 场 · S03（半明半暗）

人物：沈砚、苏听晚、空洞化男人

暗巷里，一个男人靠墙喝酒，眼神空洞。他的影子不在地面上——半悬浮在他身后，像被风掀起的黑纸片。

影子的嘴一张一合，发出尖锐嘶鸣。一只黑色的手按在男人头顶，他的身体轻轻颤了一下。

**沈砚**（平静）：在抽他的人格。第二阶段空洞化。

苏听晚想走过去，沈砚拉住了她的胳膊。

**沈砚**（看着她）：我是代理人。我只见证，不救赎。

### 第 4 场 · S02（黄昏路灯）

人物：沈砚、苏听晚

回到老街灯光下，苏听晚深深吸了一口气。

她低头看自己的影子——满街的影子都在说话都在晃，只有她的影子纯白安静，没有任何声音。

**苏听晚**（犹豫）：我的影子……是不是有什么不对？

沈砚的脚步顿了一下，没有回头。

**沈砚**（回避）：你的影子安静，也许只是因为你没有什么不敢说的话。

苏听晚没有再说话。她知道，沈砚在回避。
