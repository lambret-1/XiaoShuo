# 影笔代理人 · 剧本（第 1 集）

## 第 1 集

> 预估 51.4 秒 / 目标 60 秒 · 开场钩子：周明迟到五分钟，但步伐稳得不像他平时的样子——影子替他来开会了。（第 0 场第 0 拍兑现） · 结尾悬念：沈砚通过影契远程感知到了会议室里的一切——远程感知，首次。墨痕比昨天又深了一分。
> 认领爽点：悬念钩、打脸、情感爆点、结尾悬念

### 第 1 场 · S01（日光灯上午）

人物：周明、赵国栋　道具：P01

长条形会议室坐了十二个人，主管赵国栋坐在主位，手指不耐烦地敲桌面。

门开了，周明走进来。头发比平时整齐，手里攥着文件夹，步伐很稳。

**赵国栋**（抬眼扫了一圈，不耐烦）：周明呢？又迟到？

周明没有道歉。他走到座位前，站着，把文件夹放在桌上。

**周明**（声音不高，但会议室里每个人都听得清）：赵主管。这是近三年，我参与的十一个项目的原始图纸。

周明又拿出一叠纸放在桌上。主管的脸色变了。

**周明**（目光平静得可怕）：这是项目组的内部邮件记录。一共一百四十七封。

**赵国栋**（猛地站起来，脖子红到耳后）：周明！你知不知道你在说什么？！

**周明**（一字一句）：我知道。上个月城西综合体，你把我的设计拿去评了省优。

周明从文件夹里拿出最后一张纸，放在桌上。

**周明**（顿了顿，看着主管的眼睛）：这是我的离职申请。今天生效。

**周明**（一字一句，平静）：还有，我不是废物。

### 第 2 场 · S02（上午阳光）

人物：沈砚

同一时刻，一心堂画室。沈砚坐在画架前，闭着眼睛。

他的右手手背上，墨痕在发烫。不是刺痛，是温热的、流动的东西。

他「看见」了——一间会议室，一个穿灰工装的男人站起来，把一叠纸放在桌上。

他听见那个男人说：我不是废物。然后，连接断了。

沈砚睁开眼睛。低头看右手，墨痕比昨天又深了一分。
